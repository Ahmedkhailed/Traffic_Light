# 🚦 Traffic Light Simulation

This is a simple C# Windows Forms application that simulates a traffic light system.  
It's a basic project created to practice and demonstrate the use of:

- ✅ **Events**
- ✅ **Lambda Expressions**
- ✅ **Multithreading**

## 💡 Features

- Simulates traffic lights (Red, Yellow, Green)
- Event-driven control updates
- Clean code with lambda expressions for conciseness

## 🧰 Technologies Used

- C#
- Windows Forms (.NET Framework)
- System.Threading
